# Output schema

This document describes the principal generated v1.1 CINTA-Chem outputs without changing production columns or their order. The production scripts are authoritative for exact values and serialization.

## 1. Active master observations

### `data/final/CINTA-Chem_Master_Observations.csv`

The final active master table contains the following 20 columns, in this order:

```text
PUBCHEM_AID
PUBCHEM_SID
PUBCHEM_CID
SMILES
PUBCHEM_ACTIVITY_OUTCOME
PUBCHEM_ASSAY_URL
RESULT_IS_ACTIVE_CONCENTRATION
PubChem_Standard_Value_uM
pPotency
PubChem_Standard_Type
Assay_Name
Target_Name
UniProtKB_ID
Gene_Symbol
Organism
KEGG_Gene_ID
KO
Protein_Family
EC_Number
Target_Class
```

## 2. Compound-level polypharmacology

### `data/final/CINTA-Chem_Polypharmacology.csv`

Generated one row per unique `PUBCHEM_CID` represented in the active master table, with the following columns:

```text
PUBCHEM_CID
SMILES
Number_of_Targets
Target_Name_List
Gene_List
UniProt_ID_List
KO_List
AID_List
Activity_Types
Number_of_Assays
Best_pPotency
Median_pPotency
Worst_pPotency
```

The list-valued columns are semicolon-delimited strings generated by the validated production script.

## 3. Target-level promiscuity

### `data/final/CINTA-Chem_Target_Promiscuity.csv`

Generated one row per unique active UniProt target and summarized with:

```text
UniProt
Gene
Organism
KO
Number_of_compounds
Number_of_observations
COMPOUND_CID_List
COMPOUND_AID_List
Median_activity
Mean_activity
Best_activity
Worst_activity
```

The list-valued columns are semicolon-delimited strings. This table is also the input target universe for the final active-branch UniProt sequence retrieval stage.

## 4. Molecular descriptors

### `data/final/CINTA-Chem_Molecular_Descriptors.csv`

Generated one row per unique PubChem CID used by the active descriptor stage:

```text
PUBCHEM_CID
SMILES
Valid_SMILES
Molecular_Weight
Exact_Molecular_Weight
cLogP
TPSA
HBD
HBA
Rotatable_Bonds
Fraction_CSP3
Heavy_Atom_Count
Ring_Count
Aromatic_Ring_Count
Murcko_Scaffold
Murcko_Scaffold_ID
```

Bemis-Murcko scaffolds are calculated with RDKit. Scaffold IDs are assigned deterministically from the sorted set of non-empty scaffold strings.

## 5. Molecular fingerprints

### `data/final/CINTA-Chem_Molecular_Fingerprints.pkl`

Pickle serialization of a mapping from PubChem CID to the RDKit Morgan fingerprint generated with:

- radius = 2;
- 2048 bits.

The fingerprint is generated for compounds for which a valid molecule can be constructed from the SMILES string.

## 6. Data-quality summary

### `data/final/CINTA-Chem_Data_Quality.csv`

Generated at the compound-target level with:

```text
PUBCHEM_CID
UniProtKB_ID
n_observations
mean_pPotency
SD
CV%
```

The validated production script computes the summary directly from the retained `pPotency` observations.

## 7. Final active-target sequence resources

### `data/final/CINTA-Chem_Target_Sequences.fasta`

FASTA file containing retrieved protein sequences keyed by the exact UniProt accession strings supplied to the sequence stage.

### `data/final/CINTA-Chem_Target_Sequence_Retrieval_Status.tsv`

Tab-delimited retrieval-status table containing:

```text
accession
status
detail
updated_utc
```

### `data/final/CINTA-Chem_Target_Sequence_Retrieval_Missing.tsv`

Tab-delimited report listing requested accessions for which no exact sequence match was retrieved.

## 8. Inactive final outputs

### `data/final/CINTA-Chem_Inactive_Master_Observations.csv`

Final inactive master table using the same 20-column final observation schema as the active master table, but containing the inactive branch. Explicit `INACTIVE` observations are preserved through potency cleaning, including observations with missing `PubChem_Standard_Value_uM`; `pPotency` is populated only where a positive numeric concentration is available.

### `data/final/CINTA-Chem_Balanced_Inactive_Compounds.csv`

Balanced inactive compound/observation dataset produced by `inactive/filtering_balanced_inactive_data.py`. The target size is defined from the active observation table and the nominal ratio is 1:1 inactive-to-active observations. Exact matching and fallback rules are implemented by that production script.

### `data/final/CINTA-Chem_Inactive_Molecular_Descriptors.csv`

Descriptor table generated from `CINTA-Chem_Balanced_Inactive_Compounds.csv` using the same descriptor set as the active branch.

### `data/final/CINTA-Chem_Inactive_Molecular_Fingerprints.pkl`

Morgan fingerprints generated from the balanced inactive compounds using radius 2 and 2048 bits.

## Schema policy

Production column names, file names, and column order are release-controlled. Changes to any of these require a versioned release and an explicit changelog entry.
